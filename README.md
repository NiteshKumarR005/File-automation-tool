# File Automation Tool

## Objective
Automate file management tasks such as renaming, sorting, and ckeaning files using python.

## Feature
- Rename files
- Sort files by type
- Clean temporary files
- Logging support
- Exception handling

## Technologies Used
- Python
- OS Module
- Logging Module
- Git and GitHub

## Requirements
-   1. Install Python 3.x on your system.
    2. Select an operation:
        - Rename Files
        - Sort Files
        - Clean Files
    3. Enter the folder path when prompted.
    4. View the results and generated logs
